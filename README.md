Phishing Website Detection

Project Overview

This project focuses on identifying phishing websites using website URLs and their labels. It uses a dataset containing URLs classified as "good" or "bad" to analyse and detect potentially harmful websites.

Objectives

- Analyse website URL data.
- Understand the difference between legitimate and phishing websites.
- Explore the dataset using Python.
- Build a machine learning model for phishing website detection.

Dataset

The project uses the "phishing_site_urls.csv" dataset.

The dataset contains:

- URL: Website address
- Label: Website classification ("good" or "bad")

Technologies Used

- Python
- Google Colab
- Pandas
- Machine Learning

Project Notebook

"RCA_PROJECT2.ipynb"

How to Run

1. Download or clone this repository.
2. Open the notebook in Google Colab.
3. Upload the dataset file "phishing_site_urls.csv".
4. Run the notebook cells sequentially.

Project Purpose

This project helps understand phishing website detection and the use of data analysis and machine learning techniques in cybersecurity.
